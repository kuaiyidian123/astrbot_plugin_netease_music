# 网易云点歌插件

基于 AstrBot Star 框架的网易云音乐点歌插件，支持在线搜索点歌、本地歌单管理、歌曲留言、Cookie 登录解锁会员音质，并可选用 B 站视频搜索与发送；所有结果以精美图片卡片呈现。

## ✨ 功能特性

- 🔍 **在线搜索点歌**：按歌名搜索网易云音乐，返回带专辑封面的图片列表
- 🎵 **多种方式发送**：语音消息 / 音频文件 / 歌曲链接（可配置）
- 📁 **本地歌单管理**：`D:\music`（可配置任意盘）下创建歌单文件夹、下载歌曲保存、按序号/歌名播放
- 🖼️ **封面自动保存**：下载歌曲时同步保存专辑封面到歌单文件夹，歌单列表秒出图
- 💬 **歌曲留言**：给歌单中的歌曲留言，发送歌曲时自动附带留言图片
- 🔑 **Cookie 登录**：浏览器 Cookie 导入（绕开加密接口限制），解锁会员音质
- 🎚️ **7 档音质**：标准 / 较高 / 极高 / 无损 / 臻音全景 / 沉浸环绕 / 超清母带
- 🎬 **B 站视频搜索与发送**（可选开启）：`/搜视频 关键词` 直接搜，或选歌时加「搜索视频」；按播放量排序出图，直接发序号即可把视频文件发到聊天
- 🖼️ **文本发送模式**：可选把全部图片结果改为纯文本发送
- 📦 **零第三方音乐库**：直连网易云官方 API（`/api/*` 非加密接口），仅依赖 Pillow + aiohttp

## 📦 安装

1. 在 AstrBot 插件管理页面上传本插件（zip 包）
2. 依赖安装：

```bash
pip install Pillow aiohttp
```

3. 重启 AstrBot，在插件管理中启用插件
4. （可选）在配置页设置音乐文件夹位置、音质、图片背景等参数
5. （可选）使用 B 站视频功能需安装 **ffmpeg** 并加入 PATH（用于合并 DASH 音视频）

## 🚀 指令速查

### 🎵 点歌播放

| 指令 | 说明 |
|------|------|
| `/点歌 <歌名>` | 搜索歌曲并返回图片列表（带封面） |
| `<序号>` 或 `/序号` | 播放搜索结果中的对应歌曲（搜索后直接发数字即可） |
| `<序号> 添加歌单 <歌单名>` | 下载该歌曲到指定歌单文件夹 |
| `<序号> 搜索视频` | 去 B 站搜索该歌曲相关视频，返回候选列表（需开启 B 站视频功能） |

### 🎬 B 站视频（需在配置中开启）

| 指令 | 说明 |
|------|------|
| `/搜视频 <关键词>` | **直接搜索 B 站视频**（按播放量降序），5×5 网格出图（每页 25 条，超出自动分页） |
| `<序号> 搜索视频` | 先 `/点歌` 搜歌，再按「歌名 + 歌手」去 B 站搜相关视频 |
| `<序号>` | 直接发送第 N 个视频文件（搜视频后发数字即为此意；`视频N` 写法也兼容） |

> 发送的是**视频文件**而非链接：插件会取 B 站 DASH 视频流与音频流并用 ffmpeg 合并为 mp4。
> 单个视频超过配置的大小上限时，改为回复视频链接；未安装 ffmpeg 时退化为发送无声视频。

### 📁 本地歌单

| 指令 | 说明 |
|------|------|
| `/创建歌单 <歌单名>` | 在音乐根目录下新建歌单文件夹（`/创造歌单` 为兼容别名） |

| `/歌单 <歌单名> <序号>` | 按序号播放歌单中的歌曲（语音） |
| `/歌单 <歌单名> <歌曲名>` | 按歌名模糊匹配播放 |
| `/歌单 <歌单名> 下载歌曲 <序号>` | 发送歌单中该序号歌曲的 mp3 文件 |
| `/歌单 <歌单名> 下载歌曲 <歌曲名>` | 联网搜索下载该歌到歌单并发送 mp3 文件 |
| `/补封面 <歌单名>` | 为歌单中缺少本地封面的歌曲批量补齐封面 |

### 💬 歌曲留言

| 指令 | 说明 |
|------|------|
| `/留言 <歌单名> <序号> <内容>` | 给歌单中指定歌曲留言（显示 QQ 昵称） |
| `/留言 <歌单名> <歌曲名> <内容>` | 按歌名留言 |

| `/留言 <歌单名> 公开` | 开启/关闭公开留言（开启后所有人可留言） |

### 🗑️ 删除管理

| 指令 | 说明 |
|------|------|
| `/删除留言 <歌单名> <序号>` | 删除该歌曲全部留言 |
| `/删除留言 <歌单名> <序号> <留言序号>` | 删除指定一条留言 |
| `/删除歌曲 <歌单名> <序号/歌名>` | 删除歌单中的歌曲文件（同步清理留言） |

### 👑 歌单绑定（所有权）

绑定歌单后，仅歌单主（绑定者）与其邀请的成员可以添加/删除歌曲、管理留言；**未绑定的歌单需先绑定后才能管理**（下载歌曲、留言、补封面等会提示先绑定）。

| 指令 | 说明 |
|------|------|
| `/绑定 <歌单名>` | 绑定歌单，成为歌单主（每个歌单只能被一人绑定） |
| `/绑定邀请 <歌单名> @人` | 邀请他人共同管理（对方需 3 分钟内同意） |
| `/同意绑定 <歌单名>` | 接受邀请，成为歌单成员 |
| `/绑定查看 <歌单名>` | 生成图片查看歌单主与成员（受邀成员标注「邀请用户」） |
| `/解绑 <歌单名> @人` | 歌单主移除共享成员 |

> 绑定信息保存在歌单文件夹下的 `binding.json`。歌单主拥有最高权限，可移除成员；成员之间权限相同。

## 🔑 Cookie 导入教程

1. 浏览器打开 `music.163.com` 并登录你的账号
2. 按 **F12** 打开开发者工具 → **Application（应用程序）** 标签
3. 左侧 **Cookies** → 点 `https://music.163.com`
4. 找到 **MUSIC_U** 这一行（HttpOnly，JS 拿不到，必须在这里复制），复制它的 **Value**
5. 回到 AstrBot 发送：

```
/导入cookie MUSIC_U=你复制的值
```

> 💡 技巧：也可在 Console 执行 `copy(document.cookie)` 复制全部 Cookie 后整段导入；但完整 Cookie 只包含非 HttpOnly 部分，**MUSIC_U 仍需在 Application 面板单独获取**。

## 🎬 B 站视频配置说明

两个入口各自独立开关，**互不依赖**，可任意组合开启：

| 开关 | 默认 | 控制的入口 |
|------|------|-----------|
| 开启「选歌搜视频」（按歌曲搜） | 关 | `/点歌 歌名` → `1 搜索视频` |
| 开启「/搜视频」直接搜索 | 开 | `/搜视频 关键词` |

1. 按需打开上面两个开关（总效果：开启哪个入口，对应指令就可用）
2. 可选填写 **B站 SESSDATA**：浏览器登录 bilibili.com → F12 → Application → Cookies → 复制 `SESSDATA` 的值。填入后画质更高、更不容易被风控；留空为匿名访问（通常只有 360P/480P）
3. 其余可调：单个视频大小上限（默认 50MB，超限改发链接）、视频搜索数量上限（1~100，每页 25 条自动分页）

图片背景与点歌/帮助图各自独立，两个入口的列表图也**各有一套**设置，可分别配置成不同风格：

**「选歌搜视频」列表图**

| 配置项 | 说明 |
|--------|------|
| 视频列表图使用随机背景图 | 独立开关；开启后从随机图接口自动取图并定时更换 |
| 视频列表图随机图接口 | 可单独指定接口，留空则沿用通用「随机图 API 地址」 |
| 视频列表图分辨率 | 格式 `宽x高`，例如 `4320x2236`，不填默认自适应 |
| 视频列表图背景图 | 在后台直接上传固定背景图 |

**「/搜视频」列表图**（同样四项，与上面那套互不影响）

| 配置项 | 说明 |
|--------|------|
| 「/搜视频」列表图使用随机背景图 | 独立开关与独立缓存文件 `random_bg_cmd.jpg` |
| 「/搜视频」列表图随机图接口 | 可单独指定接口，留空则沿用通用「随机图 API 地址」 |
| 「/搜视频」列表图分辨率 | 格式 `宽x高`，例如 `4320x2236`，不填默认自适应 |
| 「/搜视频」列表图背景图 | 在后台直接上传固定背景图 |

## 📂 文件结构

```
D:\music\                        ← 音乐根目录（可在配置中修改）
└── 我的歌单\
    ├── 周杰伦 - 晴天.mp3         ← 歌曲文件
    ├── cover_周杰伦 - 晴天.jpg  ← 本地封面（渲染歌单列表用）
    ├── binding.json             ← 歌单绑定成员信息（歌单主/成员/待接受邀请）
    ├── comments.json            ← 该歌单所有歌曲的留言
    └── .netease_playlist        ← 插件歌单标记文件

data/plugin_data/astrbot_plugin_netease_music/
├── cookies.json                 ← 登录凭证
├── random_bg_search.jpg         ← 随机背景图缓存（点歌图）
├── random_bg_help.jpg           ← 随机背景图缓存（帮助图）
├── random_bg_video.jpg          ← 随机背景图缓存（选歌搜视频列表图）
└── random_bg_cmd.jpg            ← 随机背景图缓存（/搜视频 列表图）
```

## ⚠️ 异常处理

- 歌单不存在 → 提示先创建
- 歌单未绑定 → 提示先 `/绑定` 再管理
- 歌曲/序号不存在 → 提示未找到
- 搜索无结果 → 提示未找到
- 音频 URL 获取失败 / 下载失败 → 提示下载失败
- B 站视频下载失败或超限 → 提示原因并附视频链接
- 磁盘读写异常 → 提示错误原因
- 无会员权限时高音质自动回退到可用音质
