# 网易云点歌插件

基于 AstrBot Star 框架的网易云音乐点歌插件，支持在线搜索点歌、**搜索网易云歌单并整单下载**、本地歌单管理、歌曲留言、Cookie 登录解锁会员音质，可选用 B 站视频搜索与发送，并可选接入 **NovelAI 生图**；所有结果以精美图片卡片呈现。

## ✨ 功能特性

- 🔍 **在线搜索点歌**：按歌名搜索网易云音乐，返回带专辑封面的图片列表
- 🎵 **多种方式发送**：语音消息 / 音频文件 / 歌曲链接（可配置）
- 📁 **本地歌单管理**：`D:\music`（可配置任意盘）下创建歌单文件夹、下载歌曲保存、按序号/歌名播放
- 🖼️ **封面自动保存**：下载歌曲时同步保存专辑封面到歌单文件夹，歌单列表秒出图
- 💬 **歌曲留言**：给歌单中的歌曲留言，发送歌曲时自动附带留言图片
- 🔑 **Cookie 登录**：浏览器 Cookie 导入（绕开加密接口限制），解锁会员音质
- 🎚️ **7 档音质**：标准 / 较高 / 极高 / 无损 / 臻音全景 / 沉浸环绕 / 超清母带
- 🎬 **B 站视频搜索与发送**（可选开启）：`/搜视频 关键词` 直接搜，或选歌时加「搜索视频」；按播放量排序出图，直接发序号即可把视频文件发到聊天
- 🎧 **网易云歌单搜索**（可选开启）：`/搜歌单 关键词` 出图选歌单 → 查看全部歌曲（每页 50 首）→ 发 `序号 下载歌单` 整单下载到本地歌单；也支持 `/搜歌单 歌单链接 [下载]`
- 🎨 **NovelAI 生图**（可选开启）：`/生图 中文描述`，先由大模型转成英文绘画 tag，再调用 NovelAI 生成二次元插画
- 🖼️ **文本发送模式**：可选把全部图片结果改为纯文本发送
- 📦 **零第三方音乐库**：直连网易云官方 API（`/api/*` 非加密接口），仅依赖 Pillow + aiohttp

## 📦 安装

1. 在 AstrBot 插件管理页面上传本插件（zip 包）
2. 依赖安装：

```bash
pip install Pillow aiohttp
```

3. 重启 AstrBot，在插件管理中启用插件
4. （可选）在配置页设置音乐文件夹位置、音质、图片背景等参数
5. （可选）使用 B 站视频功能需安装 **ffmpeg** 并加入 PATH（用于合并 DASH 音视频）
6. （可选）使用 **NovelAI 生图**需在 AstrBot 中已配置至少一个对话模型（用于中文→英文 tag 转换），并在后台填写下方「生图」相关配置

## 🚀 指令速查

### 🎵 点歌播放

| 指令 | 说明 |
|------|------|
| `/点歌 <歌名>` | 搜索歌曲并返回图片列表（带封面） |
| `<序号>` 或 `/序号` | 播放搜索结果中的对应歌曲（搜索后直接发数字即可） |
| `<序号> 添加歌单 <歌单名>` | 下载该歌曲到指定歌单文件夹 |
| `<序号> 搜索视频` | 去 B 站搜索该歌曲相关视频，返回候选列表（需开启 B 站视频功能） |

### 🎧 搜歌单（网易云歌单搜索，需在配置中开启）

| 指令 | 说明 |
|------|------|
| `/搜歌单 <关键词>` | 搜索网易云歌单，5×5 网格出图（方形封面 + 歌单名 + 歌曲数 + 创建者） |
| `<序号>` | 查看该歌单**全部歌曲**（每页 50 首，超出自动分页） |
| `<序号> 下载歌单` | 把该歌单**整单下载**到本地歌单文件夹 |
| `<序号>`（歌曲列表） | 发送该歌曲的音频（发送方式与 `/选歌` 一致，受「音频发送方式」控制） |
| `/搜歌单 <歌单链接>` | 按分享链接打开歌单，返回全部歌曲（每页 50 首） |
| `/搜歌单 <歌单链接> 下载` | 把该歌单整单下载到本地歌单文件夹 |

> 链接支持 `https://music.163.com/playlist?id=xxx`、`https://music.163.com/#/playlist?id=xxx`，以及 `163cn.tv` 短链（自动跟随跳转解析出歌单 id）。
> 整单下载时：本地歌单**不存在则自动创建**（用网易云歌单名，过滤非法字符并截断到 15 字符）并**自动把发起人绑定为歌单主**；已存在则必须是本插件创建的歌单，且发起人具备管理权限。已下载过的歌曲会自动跳过。
> 发序号时按「最近一次搜索」判断：最近搜的是**歌单 → 看歌单歌曲**，最近搜的是**歌单歌曲 → 发音频**，最近搜的是**歌 → 点播歌曲**，最近搜的是**B 站视频 → 发视频**。

### 🎬 B 站视频（需在配置中开启）

| 指令 | 说明 |
|------|------|
| `/搜视频 <关键词>` | **直接搜索 B 站视频**（按播放量降序），5×5 网格出图（每页 25 条，超出自动分页） |
| `<序号> 搜索视频` | 先 `/点歌` 搜歌，再按「歌名 + 歌手」去 B 站搜相关视频 |
| `<序号>` | 直接发送第 N 个视频文件（搜视频后发数字即为此意；`视频N` 写法也兼容） |

> 发送的是**视频文件**而非链接：插件会取 B 站 DASH 视频流与音频流并用 ffmpeg 合并为 mp4。
> 单个视频超过配置的大小上限时，改为回复视频链接；未安装 ffmpeg 时退化为发送无声视频。

### 🎨 AI 生图（NovelAI，需在配置中开启）

| 指令 | 说明 |
|------|------|
| `/生图 <中文描述>` | 先由大模型把描述转成英文绘画 tag，再调用 NovelAI 出图 |
| `/生图帮助` | 查看当前生图配置、今日剩余次数与可用的大模型 ID |

> 转换规则已内置：只输出绘画关键词、`masterpiece, best quality` 打头、负面词固定包含 `lowres, bad anatomy, bad hands, extra limbs, deformed, blurry, ugly`；大模型漏写时插件会**自动补齐**。
> 生图会消耗 NovelAI 的 **Anlas** 额度，建议在后台设置「每人每日生图次数上限」（默认 5 次/天，且仅在**生成成功后**计数）。

## 🔑 Cookie 导入教程

1. 浏览器打开 `music.163.com` 并登录你的账号
2. 按 **F12** 打开开发者工具 → **Application（应用程序）** 标签
3. 左侧 **Cookies** → 点 `https://music.163.com`
4. 找到 **MUSIC_U** 这一行（HttpOnly，JS 拿不到，必须在这里复制），复制它的 **Value**
5. 回到 AstrBot 发送：

```
/导入cookie MUSIC_U=你复制的值
```

> 💡 技巧：也可在 Console 执行 `copy(document.cookie)` 复制全部 Cookie 后整段导入；但完整 Cookie 只包含非 HttpOnly 部分，**MUSIC_U 仍需在 Application 面板单独获取**。

## 🎬 B 站视频配置说明

两个入口各自独立开关，**互不依赖**，可任意组合开启：

| 开关 | 默认 | 控制的入口 |
|------|------|-----------|
| 开启「选歌搜视频」（按歌曲搜） | 关 | `/点歌 歌名` → `1 搜索视频` |
| 开启「/搜视频」直接搜索 | 开 | `/搜视频 关键词` |

1. 按需打开上面两个开关（总效果：开启哪个入口，对应指令就可用）
2. 可选填写 **B站 SESSDATA**：浏览器登录 bilibili.com → F12 → Application → Cookies → 复制 `SESSDATA` 的值。填入后画质更高、更不容易被风控；留空为匿名访问（通常只有 360P/480P）
3. 其余可调：单个视频大小上限（默认 50MB，超限改发链接）、视频搜索数量上限（1~100，每页 25 条自动分页）

图片背景与点歌/帮助图各自独立，两个入口的列表图也**各有一套**设置，可分别配置成不同风格：

**「选歌搜视频」列表图**

| 配置项 | 说明 |
|--------|------|
| 视频列表图使用随机背景图 | 独立开关；开启后从随机图接口自动取图并定时更换 |
| 视频列表图随机图接口 | 可单独指定接口，留空则沿用通用「随机图 API 地址」 |
| 视频列表图分辨率 | 格式 `宽x高`，例如 `4320x2236`，不填默认自适应 |

**「/搜视频」列表图**（同样四项，与上面那套互不影响）

| 配置项 | 说明 |
|--------|------|
| 「/搜视频」列表图使用随机背景图 | 独立开关与独立缓存文件 `random_bg_cmd.jpg` |
| 「/搜视频」列表图随机图接口 | 可单独指定接口，留空则沿用通用「随机图 API 地址」 |
| 「/搜视频」列表图分辨率 | 格式 `宽x高`，例如 `4320x2236`，不填默认自适应 |

## 🎨 NovelAI 生图配置说明

1. **开启「/生图」** 开关（默认关，生图会消耗 Anlas）
2. **填 API 地址**：默认 `https://image.novelai.net/ai/generate-image`
   - ⚠️ 旧域名 `api.novelai.net` 已不支持新模型（会返回 400 `model must be a valid enum value`），不要用它
   - 使用第三方中转服务时，填其中转地址
3. **填 API Key**：NovelAI 的**持久化 Token**，形如 `pst-...`
   - 获取方式：登录 novelai.net → 右下角 **Account / 设置** → **API Tokens** → 新建并复制
   - 注意：**不是**登录用的 access token，两者不通用
4. **选模型**：默认 `nai-diffusion-4-5-full`；也可填 `nai-diffusion-4-5-curated`、`nai-diffusion-5-full`、`nai-diffusion-3`
5. **调参数**：尺寸 / 步数 / CFG / 采样器 / 额外负面词，全部可留默认
6. **指定转换模型**：在「生图 tag 转换模型 ID」填本实例已有的大模型 ID；**留空则用 AstrBot 当前默认对话模型**。可用 ID 可发送 `/生图帮助` 查看
7. **设次数上限**：`每人每日生图次数上限` 默认 5，填 0 不限

> 请求体已按 V4.5/V5 规范构建，**同时携带 `v4_prompt` 与 `v4_negative_prompt`**（缺任意一个服务端会直接返回 500）；响应兼容 **ZIP 包（官方格式）与裸 PNG/JPEG**，自动解包。
> 401（Token 无效）/ 402（额度不足）/ 429（限流）/ 500 等错误都会转成可读中文提示。

## ⚠️ 异常处理

- 歌单不存在 → 提示先创建
- 歌单未绑定 → 提示先 `/绑定` 再管理
- 歌曲/序号不存在 → 提示未找到
- 搜索无结果 → 提示未找到
- 音频 URL 获取失败 / 下载失败 → 提示下载失败
- B 站视频下载失败或超限 → 提示原因并附视频链接
- 歌单搜索/歌单歌曲无结果 → 提示未找到或歌单为空
- 歌单链接无法解析（非歌单链接）→ 提示需提供歌单分享链接
- 整单下载失败的回退：歌单不存在则自动创建；同级已有同名非插件目录 → 拒绝写入；歌单已被他人绑定 → 提示权限不足
- 生图未配置 API Key → 提示联系管理员配置
- 生图未找到可用对话模型 → 提示先配置模型或改用默认模型
- 大模型输出不符合「正向tag/负面tag」格式 → 提示重试或换个描述
- NovelAI 返回 401 / 402 / 429 / 5xx → 分别提示 Token 无效、额度不足、限流、服务异常
- 生图解析不出图片或响应超过 32MB → 提示检查 API 地址
- 磁盘读写异常 → 提示错误原因
- 无会员权限时高音质自动回退到可用音质
